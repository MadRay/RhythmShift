# RhythmShift

Dynamic Baby Sleep Rhythm & Schedule Architect — help sleep-deprived parents manage and adapt a newborn's sleep routine with wake-window tracking, voice logging, and multi-day projections.

## Quick start

```bash
npm install
npm run dev
```

## Features

- **Deterministic schedule engine** — age-based wake windows, short-nap reroutes, bridge naps, day-nap caps
- **Voice-first logging** — Web Speech API with regex event extraction and text fallback
- **Countdown hero** — live phase, progress ring, and tired-cue guidance
- **Day timeline + 3-day forecast** — visual rhythm for today and upcoming circadian projections
- **Sleep consultant chat** — on-device Q&A with quick chips
- **Demo toolbar** — simulate morning wake, wind-down, short-nap disaster, and baseline reset

## Stack

React · Vite · TypeScript · Tailwind CSS · lucide-react
